# Python Automation & Web Development Portfolio

This repository contains a collection of Python-based automation tools, web scraping scripts, and dynamic web applications designed to solve real-world data extraction and processing tasks.

## 📂 Project Structure

* **`Automated PDF & Invoice Generator/`**: Python scripts utilizing ReportLab to automatically generate structured PDF documents and professional invoices.
* **`ecommerce_scraper/`**: Web scraping pipelines built with BeautifulSoup, Requests, and Pandas to extract, clean, and export structured product data.
* **`excel_automation/`**: Data processing scripts utilizing Openpyxl and Pandas for automated Excel report generation and spreadsheet manipulation.
* **`flask web/`**: A fully functional interactive web application built with **Flask**, integrated with the **Groq AI SDK** (`qwen/qwen3.8-27b`) to provide dynamic user age calculations and AI-generated technology facts with markdown formatting support.

## 🛠️ Technologies Used
* **Language:** Python 3.15
* **Web Framework:** Flask, Jinja2
* **AI Integration:** Groq SDK (`qwen/qwen3.8-27b`)
* **Data Processing & Scraping:** Pandas, BeautifulSoup, Requests, Openpyxl
* **Document Generation:** ReportLab, Markdown
